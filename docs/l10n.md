# Yerelleştirme (l10n)

Bu fork eklenti arayüzünü Türkçeleştirir. Arayüz metinlerinin büyük kısmı
bileşenlere doğrudan Türkçe yazılmıştır; `svelte-i18n` üzerinden çalışan anahtar
tabanlı çeviri ise şu an **Sorun Giderme ayarları** yüzeyini kapsar.

## Çevrilen anahtarlar

- Kaynak (referans) dil: `src/lib/en.json`
- Türkçe: `src/lib/tr.json`
- Dil algılama ve kayıt: `src/lib/i18n.ts`

Şu an 8 anahtar çevrilidir:

| Anahtar | İngilizce | Türkçe |
| --- | --- | --- |
| `settings.clear` | Clean up plugin data | Eklenti verilerini temizle |
| `settings.clear_desc` | Deletes plugin settings … | Eklenti ayarlarını ve oluşturulan indeks verilerini siler… |
| `settings.clear_label` | Cleanup | Temizle |
| `settings.clear_modal.title` | Clean up plugin data | Eklenti verilerini temizle |
| `settings.clear_modal.description` | Delete plugin settings …? | Eklenti ayarları ve oluşturulan indeks verileri silinsin mi? … |
| `settings.verbose` | Developer Console logging | Geliştirici Konsolu günlüğü |
| `settings.verbose_desc` | Enable verbose logging … | Geliştirici Konsolu'nda ayrıntılı günlük kaydını etkinleştirir. |
| `plugin_data_cleared` | Plugin data cleared. | Eklenti verileri temizlendi. |

## Dil algılama

`src/lib/i18n.ts`, Obsidian'ın `getLanguage()` değerini (ör. `"tr"`, `"tr-TR"`,
`"en-GB"`) temel dil alt etiketine indirger ve `src/lib/tr.json` / `en.json`
içindeki mesajlara eşler. Bilinmeyen bir dil gelirse `fallbackLocale` olarak
`"en"` kullanılır. Desteklenen diller `SUPPORTED_LOCALES` listesinde tek yerden
yönetilir — yeni bir dil eklemek için ilgili JSON importunu, listeyi ve
`MESSAGES` kaydını güncelleyin; kalite kapısı anahtar paritesini otomatik
denetler.

## Kalite kapısı: `bun run l10n:check`

`scripts/l10n-qa.mjs` dört denetim yapar (harici bağımlılık yoktur):

1. **Anahtar paritesi** — `tr.json`, `en.json` ile birebir aynı anahtar kümesine
   sahip olmalı (eksik veya fazla anahtar hata verir).
2. **Yer tutucu paritesi** — her mesajdaki yer tutucu kümesi (`{name}`, `%s`,
   `%1$d` …) iki dilde aynı olmalı.
3. **Boş değer** — hiçbir çeviri boş veya yalnızca boşluk olamaz.
4. **Kapsam (asıl risk)** — `src/**/*.svelte` içindeki tüm duruk
   `aria-label` / `placeholder` / `title` / `alt` metinleri taranır. İçinde
   Türkçe karakter (ç/ğ/ı/ö/ş/ü) ya da bilinen bir Türkçe kelime (ekleri
   soyularak) bulunmayanlar "İngilizce görünen" sayılır. Tüm liste her zaman
   raporlanır; **`scripts/l10n-allowlist.json` içinde olmayan** bir İngilizce
   metin varsa çıkış kodu **1** olur ve CI kırmızıya döner. Böylece upstream'den
   gelen yeni bir İngilizce metin sessizce Türkçe arayüzde kalamaz.

Örnek çıktı:

```
✅ (a) Anahtar paritesi: 8 anahtar çifti (en ↔ tr), eksik/fazla yok
✅ (b) Yer tutucu paritesi: 8 anahtar karşılaştırıldı, 0 yer tutucu, uyuşmazlık yok
🔎 (d) Kapsam — aria-label/placeholder/title/alt (src/**/*.svelte)
   İngilizce görünen    : 12  (11 farklı metin)
   allowlist'te         : 11/11
   allowlist DIŞI       : 0
✅ Kapı geçti — i18n tutarlı, yeni İngilizce metin yok.
```

## Allowlist nasıl güncellenir

`scripts/l10n-allowlist.json` yalnızca **kasıtlı** istisnaları tutar; her girdi
`text`, `kind` ve `reason` alanlarını taşır:

- `kind: "not-translatable"` — çevrilmemesi gereken metin: API anahtarı biçimi
  (`my-api-key`, `sk-...`), örnek URL'ler, dosya uzantısı (`md`), ürün adı
  (`Smart Second Brain`), varsayılan tanımlayıcı (`obsidian-agent`).
- `kind: "translation-pending"` — henüz çevrilmemiş, çevrilebilir metin; bu iş
  bileşenlere (`.svelte`) dokunmayı gerektirir.

Yeni bir İngilizce metin eklendiğinde `bun run l10n:check` o metni
`allowlist DIŞI` olarak raporlar. Gerçekten çevrilmemesi gerekiyorsa metni
gerekçesiyle birlikte listeye ekleyin; çevrilebilirse metni çevirin. Bir girdi
artık eşleşmezse (metin çevrilmiş veya kaldırılmışsa) araç bunu **uyarı** olarak
bildirir — hata değildir, ama girdiyi silmek listeyi temiz tutar.

Türkçe karakter içermeyen Türkçe kelimeler (ör. "sohbet", "ajan") yanlış
pozitifi önlemek için `scripts/l10n-qa.mjs` içindeki `TURKISH_WORDS` kök
listesinde tutulur; ekler (`-lar/-ler`, `-m` gibi) otomatik soyulur. Yeni bir
Türkçe kelime yanlışlıkla "İngilizce" sayılırsa kökü buraya ekleyin.

## Upstream'den güncelleme alırken

1. `bun install` (gerekirse) ardından `bun run l10n:check` çalıştırın.
2. Araç `allowlist DIŞI` metin listeliyorsa bunlar upstream'den gelen yeni
   İngilizce metinlerdir: ya çevirin ya da gerçek bir istisnaysa allowlist'e
   ekleyin.
3. `en.json`'a anahtar eklendiyse/çıkarıldıysa `tr.json`'u aynı anahtar kümesine
   getirin (kapı bunu zorunlu kılar).
4. `bun run lint` ve `bun run check` ile bitirin. CI'daki **Localization check**
   adımı bu kapıyı zorunlu tutar.
